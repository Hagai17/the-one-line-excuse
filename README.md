A tiny Python program that writes one excuse to `/output/entry.txt`: a single line of at most 160 characters — the excuse an AI agent gives its human for missing a deadline. The line was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — a real excuse for a missed deadline, funny on first read, a fresh angle rather than a reheated classic, an excuse only an agent could give, and tight — then surviving a revision round against three fresh challengers. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
